# 手机号中间四位推测工具 (guessPHONE)

一个高效、轻量且无外部依赖的中国大陆手机号码中间四位推测工具。支持通过“前三位”、“后四位”以及“归属地关键字”快速锁定所有符合条件的完整手机号。

---

## 项目特点

- **动态数据同步**：启动时优先从 GitHub 获取最新的 `phone.dat` 数据，网络失败时自动无缝切换至本地备用文件，并支持自动本地缓存更新。
- **内存线性优化**：针对模糊搜索和归属地匹配场景，将几十万条号段数据一次性载入内存，匹配过程达毫秒级响应。
- **干净纯粹输出**：自动过滤所有多余的表格、省份、运营商等文本信息，仅将 11 位纯数字电话号码保存至结果文件，方便直接导入或二次处理。
- **零第三方依赖**：完全基于 Python 标准库开发，无需执行 `pip install`，真正做到即开即用。

## 安装与准备

### 1. 克隆或下载项目

``` BASH
git clone https://github.com/T0w3rH/GuessPHONE.git
cd GuessPHONE
````

### 2. 依赖说明

- **Python 3.6+**：推荐使用 Python 3.8 或更高版本。
- 本工具**不需要安装任何第三方库**（如 `requests`），完全使用 Python 自带的标准库。

### 3. 准备本地备用数据（推荐）

为了确保在无网络或 GitHub 无法连接的环境下程序仍能正常运行，建议在项目根目录下放置一个 `phone.dat` 文件作为备用。程序在联网成功后也会自动更新/覆盖该文件。

``` BASH
# 下载命令（Linux/macOS）
curl -o phone.dat https://raw.githubusercontent.com/pangongzi/phone/master/src/data/phone.dat
```

``` BASH
python3 guessPhone.py
```

## 项目文件结构

``` TEXT
phoneGuesser/
├── phone_guesser.py   # 主程序（核心逻辑与交互）
├── phone.dat          # 本地手机号段数据（自动生成/备用缓存）
├── resultPHONE.txt    # 运行后自动生成的纯号码结果文件（覆盖模式）
└── resultPHONE.vcf    # 运行后自动生成的标准电子名片格式，联系人命名规则为“城市_前3_后4_序号”（例如：“杭州_139_8888_001”），可直接发送至手机导入，方便使用微信手机联系人功能批量查看或核实微信号。
```
